# Объяснимый ИИ в СППР

Сайт (index.html, style.css) — Render Static Site: Build пустой, Publish Directory `.`

Демо (app.py) — Render Web Service: Build `pip install -r requirements.txt`, Start `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`, переменная `PYTHON_VERSION=3.12.8`.

Блокнот xai_credit_scoring.ipynb запускается в Google Colab.
